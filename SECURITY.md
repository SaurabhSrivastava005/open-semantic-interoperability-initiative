# Security Policy

## Current status

This repository initially contains specifications, templates and synthetic examples. Do not submit production credentials, personal data, confidential schemas or sensitive institutional information.

## Reporting a vulnerability

Do not disclose exploitable vulnerabilities through a public issue. Contact the repository maintainers privately through GitHub's security advisory feature when available.

Reports should include the affected component, reproduction steps, potential impact and any suggested mitigation.

## AI and data safety

- Treat AI-generated mappings as untrusted proposals until reviewed.
- Use synthetic or explicitly authorised data in examples and tests.
- Keep deterministic validation between AI output and publication.
- Record provenance, model or method, reviewer and approval status.
- Do not use restricted data for model training or evaluation without explicit authority.
