# Government and Public Services Standards Landscape

## Scope

This landscape covers cross-agency exchange, public data catalogues, digital identity, secure data exchange and public-sector interoperability.

## Standards and models

| Standard or framework | Primary purpose | Availability and boundary | SIEL treatment |
|---|---|---|---|
| [NIEM](https://www.niem.gov/) | Cross-agency information exchange | Public model, governance and tools | Evaluate for message and domain-profile patterns |
| [DCAT 3](https://www.w3.org/TR/vocab-dcat-3/) | Interoperable data catalogues | Public W3C vocabulary | Use for dataset and data-service discovery |
| [DCAT-AP](https://interoperable-europe.ec.europa.eu/collection/semic-support-centre/solution/dcat-application-profile-data-portals-europe) | European public-data catalogues | Public application profile and controlled vocabularies | Treat as a jurisdictional profile |
| [Interoperable Europe](https://interoperable-europe.ec.europa.eu/) | Public-sector interoperability | Frameworks, reusable solutions and community assets | Reuse governance and assessment patterns |
| [X-Road](https://x-road.global/) | Secure distributed data exchange | Open-source platform and governance model | Evaluate exchange infrastructure separately from semantics |
| [W3C Verifiable Credentials](https://www.w3.org/TR/vc-data-model-2.0/) | Verifiable digital claims | Public W3C data model | Use for portable public-service credentials where justified |
| [Schema.org](https://schema.org/) | Cross-domain web vocabulary | Public vocabulary and machine-readable definitions | Use selected public-facing concepts |
| [PROV-O](https://www.w3.org/TR/prov-o/) | Provenance | Public W3C ontology | Record source and transformation history |

## Priority SIEL profiles

1. Cross-agency person and organisation exchange.
2. Public dataset discovery and provenance.
3. Licence, permit and entitlement credentials.
4. Secure service-request status exchange.
5. Policy and regulatory evidence publication.

Profiles must separate lawful authority, purpose, consent, public access, protected information and jurisdiction.
